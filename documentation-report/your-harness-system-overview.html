Living architecture snapshot · v0.1.0 foundation

Your Harness (yh)

A CLI-first engineering harness that separates governed engineering knowledge from the runtime that performs AI-assisted work.

System at a glance

Engineering core

packages/domain holds aggregates and rules; packages/application owns use cases, projections and ports.

Runtime harness

src/ composes the CLI, core infrastructure, connectors, agents, MCP, workflows and the Pi adapter.

Documentation

Markdown under docs/ is the source of truth. This report is a visual orientation layer.

The CLI command yh work-item execute <objective> currently creates a temporary approved demonstration Specification. It does not persist or transition the WorkItem.

Responsibility boundaries

Domain

Specifications, Requirements, Scenarios, WorkItems and lifecycle invariants. No prompts or provider SDKs.

Application

ContextAssembler, ExecuteWorkItemUseCase, ExecutionRequest and RuntimePort.

Runtime

Consumes execution-safe context, builds a provider prompt and returns a runtime outcome. It does not own domain authority.
